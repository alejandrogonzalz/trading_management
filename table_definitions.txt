Quant Scanner Table Definition
Column	What it Represents	How It Is Computed	Expected Value Range	Interpretation
Price	Current market price	Last candle close	positive float	Current asset value
Heatmap	Multi-EMA trend alignment	Compare EMA20, EMA50, EMA200	BULLISH / BEARISH / NEUTRAL	Shows overall trend direction
Structure	Market structure pattern	Compare recent highs/lows	BULLISH / BEARISH / RANGE / BREAKOUT	Detects trend or consolidation
RSI	Momentum strength	RSI(14)	0 – 100	Overbought or oversold conditions
MACD	Momentum shift	MACD histogram	negative → positive	Detects trend momentum changes
ADX	Trend strength	ADX(14)	0 – 100	Measures trend intensity
Volume Ratio	Relative trading activity	volume ÷ average(volume 20)	>0	Detects unusual volume
ATR Ratio	Volatility expansion	ATR ÷ avg(ATR 20)	>0	Detects volatility increases
BB Position	Position inside Bollinger Bands	(price − lower) ÷ (upper − lower)	0 – 1	Indicates overbought/oversold zones
Score	Quant confluence signal	weighted indicator scoring	0 – 10	Overall trading signal strength
AI Rank	AI-evaluated opportunity rank	LLM analyzes rows	integer ranking	Best opportunities ranked
Detailed Meaning of Each Column
Price
Attribute	Description
Value	Latest closing price
Source	OHLCV candle data
Purpose	Reference price for all indicators

Example:

BTCUSDC = 42,350.25
Heatmap (Trend Alignment)
Attribute	Description
Indicators used	EMA20, EMA50, EMA200
Logic	Compare moving averages
Purpose	Determine trend direction
Condition	Result
EMA20 > EMA50 > EMA200	BULLISH
EMA20 < EMA50 < EMA200	BEARISH
Anything else	NEUTRAL

Example output:

BULLISH

Meaning:

short term trend > mid term > long term
Structure (Market Structure)
Attribute	Description
Type	custom logic
Purpose	Detect price pattern

Uses recent highs and lows:

recent_high = max(high last N candles)
recent_low = min(low last N candles)

Example states:

Structure	Meaning
BULLISH	Higher highs forming
BEARISH	Lower lows forming
RANGE	Sideways consolidation
BREAKOUT	Price breaking resistance

Example:

BREAKOUT

Bollinger Band Position
Attribute	Description
Indicator	Bollinger Bands
Range	0 – 1
Purpose	measure price position in band

Formula:

bb_pos = (price - lower) / (upper - lower)
Position	Meaning
0	touching lower band
0.5	middle
1	touching upper band

Trading interpretation:

Range	Signal
<0.2	oversold

0.8 | overbought |

Example:

BB Position = 0.18

Meaning:

price near lower band
