# Conclusions Paper — LaTeX

Paper-style deliverable for the thesis: "Evaluación de QLoRA Fine-Tuning vs. Modelos Clásicos para Predicción Direccional en Criptomonedas."

## Compile

### macOS (MacTeX)

```bash
cd public
pdflatex Conclusions_Avance6.tex && pdflatex Conclusions_Avance6.tex
```

Two passes are needed for cross-references and hyperlinks.

### Windows (MiKTeX or TeX Live)

```powershell
cd public
pdflatex.exe Conclusions_Avance6.tex; pdflatex.exe Conclusions_Avance6.tex
```

If `pdflatex` is not in PATH, use the full path (e.g. `C:\texlive\2024\bin\windows\pdflatex.exe`).

### Prerequisites

- TeX Live 2024+ (macOS: `brew install --cask mactex`) or MiKTeX (Windows)
- Required packages (all included in standard TeX Live full): `geometry`, `graphicx`, `booktabs`, `hyperref`, `xcolor`, `amsmath`, `amssymb`, `caption`, `subcaption`, `float`, `tabularx`, `enumitem`, `titlesec`, `fancyhdr`, `babel` (spanish)

## Figures
