# LaTeX Deliverables — Thesis

Two documents live in this directory:

| File | Document | Figures |
|------|----------|---------|
| `Conclusions_Avance6.tex` | Technical report (paper) — "Evaluation of QLoRA Fine-Tuning vs. Classical Models for Directional Prediction in Cryptocurrencies" | `figures/conclusion/` |
| `Avance7_ResumenEjecutivo.tex` | Executive summary (Avance 7) | `figures/executive_summary/` |

## Build

```bash
cd public
pdflatex <file>.tex && pdflatex <file>.tex   # two passes: cross-refs + hyperlinks
```

Run two passes so `\ref`/`\label` and `hyperref` anchors resolve. On Windows with
MiKTeX, if `pdflatex` is not on `PATH`, use the full path
(e.g. `%LOCALAPPDATA%\Programs\MiKTeX\miktex\bin\x64\pdflatex.exe`).

### Prerequisites

TeX Live 2024+ or MiKTeX. Required packages:

`geometry`, `graphicx`, `booktabs`, `hyperref`, `xcolor`, `amsmath`, `amssymb`,
`caption`, `subcaption`, `float`, `tabularx`, `enumitem`, `titlesec`, `fancyhdr`,
`babel` (spanish), and — **only for `Avance7_ResumenEjecutivo.tex`** —
`tcolorbox` (with the `skins` library).

A **full** TeX Live / MiKTeX install ships all of these. The **basic** scheme does
not: `tcolorbox` and its dependencies are missing, so the executive summary fails
with `File 'tcolorbox.sty' not found` (and then `tikzfill.image.sty not found` from
the `skins` library). Install the missing packages once with `tlmgr`:

```bash
sudo tlmgr update --self          # only if tlmgr complains it is out of date
sudo tlmgr install tcolorbox tikzfill   # pulls in environ, trimspaces
```

The technical report (`Conclusions_Avance6.tex`) does not use `tcolorbox`, so it
builds on the basic scheme without extra packages.

## Figures

Figures are **split per document**. Each folder has a `src/` with the editable
sources (the `.png`/`.pdf` files are what LaTeX consumes; `src/` holds the source
that produces them):

```
public/
├── Conclusions_Avance6.tex
├── Avance7_ResumenEjecutivo.tex
├── README.md
└── figures/
    ├── conclusion/                 # technical report figures
    │   ├── figN_*.png              # generated by langgraph/optimization-results.ipynb (300 dpi)
    │   ├── fig_*.png               # diagrams (SVG / Mermaid / PlantUML exports)
    │   └── src/                    # sources: *.svg, *.mmd, *.puml
    └── executive_summary/          # executive summary figures (Avance 7)
        ├── fig_roadmap.png
        ├── fig_before_after.png
        ├── fig_lightsail_aws.png
        ├── fig_production_pipeline.png
        ├── fig4_accuracy_all_models.png   # shared with conclusion/ (copy)
        ├── fig_temporal_split.png         # shared with conclusion/ (copy)
        └── src/                    # sources: *.svg, icons/, build_lightsail_aws.py, README.md
```

- The `figN_*` plots and most `fig_*` diagrams in `conclusion/` are produced by the
  notebook `langgraph/optimization-results.ipynb` (its `savefig` calls write to
  `conclusion/`).
- Hand-authored conceptual diagrams have vector sources in the matching `src/`:
  - `conclusion/src/`: `fig_atr.svg`, `fig_qlora_mechanism.svg`, `fig_swiglu_lora.svg`,
    `fig_training_sample.svg` (plus `*.mmd`/`*.puml` for the Mermaid/PlantUML diagrams).
  - `executive_summary/src/`: all figures are SVG — see
    `figures/executive_summary/src/README.md` for how to edit and re-render to PNG.
- `fig4_accuracy_all_models` and `fig_temporal_split` are used by **both** documents:
  the canonical copy lives in `conclusion/` and is duplicated in `executive_summary/`.

### Re-rendering an SVG source to PNG

```bash
# requires librsvg (brew install librsvg)
rsvg-convert -w 1600 figures/conclusion/src/fig_atr.svg -o figures/conclusion/fig_atr.png
```
